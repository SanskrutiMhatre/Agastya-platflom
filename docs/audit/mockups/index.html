How to read these

  • Every colour is a token. The only literal colours in the pages are inside tokens.css.
  • Dark surfaces are lighter steps plus a hairline ring, not shadows. Light surfaces use shadows sparingly.
  • Status is never colour alone: each state also carries an icon, a label or a shape.
  • Focus rings, selected and selected-inactive rows, disabled and error states are shown on the editor and validation pages; hover on any control.
  • The layout is tuned for 1366 x 768 and above and does not scroll the page sideways; panels scroll inside.
